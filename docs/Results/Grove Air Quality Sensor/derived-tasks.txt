Tasks for real tests derived from measurements for the Grove Air Quality Sensor 1.3

Tasks were derived using duty cycles.

1: 10% duty cycle

for 1h: 	active:	105mA x 0,1h = 10,5mAh
		idle:	1mA x 0,9h = 0,9mAh
		sum:	10,5mAh + 0,9mAh = 11,4mAh


2: 25% duty cycle

for 1h:		active: 105mA x 0,25h = 26,25mAh
		idle:	1mA x 0,75h = 0,75mAh
		sum:	26,25mAh + 0,75mAh = 27mAh


3: 5% duty cycle

4: 1% duty cycle

for 1h:		active: 105mA x 0,001h = 1,05mAh
		idle:	1mA x 0,99h = 0,99mAh
		sum:	1,05mAh + 0,99mAh = 2,04mAh
